## 核心特性
1. **真实数据库账号密码登录**：移除所有演示快捷按钮，通过 PBKDF2 加盐哈希校验数据库 `users` 表，签发 HttpOnly Cookie 会话。
2. **外设图片存入数据库**：相册上传或手机拍照的外设照片自动压缩为 4:3 并保存至 D1 `peripherals.img_data` 字段，多台前台电脑实时同步显示。
3. **13 张关系型 D1 数据表**：涵盖账号、会话、房间房价、线上订单池、外设台账与图片、网吧外设租借、报损与维修、审计流水、夜审追缴单及交接班快照。
